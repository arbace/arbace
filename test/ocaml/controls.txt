# OCaml's negative controls (doc/GATE-SURVEY.md, GTS81 (a)): LEVEL ID SUBJECT REFERENCE, one a line.
#   expect  bin/oi suite expect (bin/lib/oi/testsuite.bash, suite_expect_one and expect_controls): the subject is run by the
#           expect tool as ocamltest runs it (the file, then -principal on its correction), and its final correction is
#           compared by the action's own comparison (cmp) with the REFERENCE's text instead of its own; the row must be
#           "diff". A control that passes (the comparison passes what differs), or ends in error or skip, or has no row
#           while its subject was selected, fails the check (before --record writes); one whose subject is not selected
#           (--only) is left. The two: expect tests of the testsuite passing in test/ocaml/ref-expect.edn. No control is a
#           row of the record or the counts.
#   judge   bin/oi check, check --aot, suite check, suite check --aot (test/ocaml/oi_check.ae, o2j_check.ae: controls-ok):
#           "judge RESULTS-FILE ID SUBJECT REFERENCE", the controls of the judgment that writes RESULTS-FILE: the subject's
#           run judged by result-of against the REFERENCE's reference run (ocamlc's at oi's level, ocamlopt's at the AOT
#           level); it must fail. One that passes, or whose reference has no reference run, fails the judgment before it
#           records; one whose subject has no run (--only) or no judgment of its own is left. The two: passing at both
#           levels in the records, with other outputs.
