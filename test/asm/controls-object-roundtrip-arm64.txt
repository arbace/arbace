# The negative controls of arm64's object round trip (judge-rest, 2026-11-20; bin/repr-asm --arch arm64 object-roundtrip,
# arbace.asm.arm64.objrt): each subject's object (its image, linked alone) held to forms that are not its source's must differ
# (a64i's forms check finds an instruction that is not the word there), its subject passing by itself. Two kinds, fields split by
# blanks:
#   ID SUBJECT REFERENCE              another file's forms (CORPUS/NAME, at the same layout as the subject's)
#   ID SUBJECT mutant LINE OLD NEW    the subject's own source with OLD on its line LINE replaced by NEW (one immediate, one
#                                     register, one relocation's symbol or addend), laid out with the subject's stub at its layout
# A control whose subject or reference is not in a run is left out of it; one that does not differ, or whose subject does not pass
# by itself, fails the command.
